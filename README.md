# SoftCast
Simulador de redes (SoftCast) que integra Teoría de Grafos para topología, IA (GNN) para detección de anomalías y Autómatas Finitos para validar protocolos. Desarrollado en Python bajo arquitectura MVC por María F. Mantilla y Mauricio García.

## Instalación

Se requiere Python 3.13 o superior. Instala las dependencias con:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Las versiones de las bibliotecas están registradas en [dependencies.json](dependencies.json).
Para ejecutar el simulador:

```powershell
python main.py
```
